# 03. Pruebas y evidencia

## Casos cubiertos

- documento sin roles: rechazado;
- consulta autorizada: permitida;
- consulta no autorizada: denegada;
- repositorio con base de prueba: persiste y recupera;
- fallo controlado de persistencia: manejado.

## Evidencia

- comandos de validacion;
- salida de pruebas;
- historial Git;
- archivos PlantUML editables.
